A sleek, modern web application that instantly converts temperatures between **Celsius (°C)**, **Fahrenheit (°F)**, and **Kelvin (K)** — featuring a premium glassmorphism UI, full input validation, and responsive design.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🔄 **Real-time Conversion** | Converts to all three units simultaneously |
| ✅ **Input Validation** | Rejects empty, non-numeric, and invalid values |
| 🥶 **Absolute Zero Guard** | Prevents conversions below physical absolute zero |
| 🎨 **Glassmorphism UI** | Premium frosted-glass design with animated gradient orbs |
| 📱 **Fully Responsive** | Optimised for desktop, tablet, and mobile |
| ♿ **Accessible** | Semantic HTML, ARIA attributes, keyboard navigation |
| ⚡ **Zero Dependencies** | Pure HTML + CSS + Vanilla JavaScript |
| 🌈 **Micro-animations** | Smooth hover effects, staggered card reveals, shake on error |

---

## 🧮 Temperature Conversion Formulae

| Conversion | Formula |
|------------|---------|
| Celsius → Fahrenheit | `°F = (°C × 9/5) + 32` |
| Fahrenheit → Celsius | `°C = (°F − 32) × 5/9` |
| Celsius → Kelvin | `K = °C + 273.15` |
| Kelvin → Celsius | `°C = K − 273.15` |

1. **Clone the repository**


