## ✨ Features

- **Dark + Neon Theme** — Sleek dark background with vibrant purple and cyan accents
- **Glassmorphism UI** — Frosted-glass cards with backdrop blur effects
- **Smooth Animations** — Scroll-reveal animations, hover effects, and micro-interactions
- **Typing Effect** — Dynamic role title animation in the hero section
- **Fully Responsive** — Mobile-first design that adapts to all screen sizes (360px → 1440px+)
- **Sticky Navigation** — Smart navbar with scroll-based background and active link highlighting
- **Accessible** — Semantic HTML5, ARIA labels, keyboard navigation, reduced-motion support
- **SEO Optimized** — Meta tags, Open Graph data, proper heading hierarchy
- **Clean Code** — CSS custom properties, BEM methodology, well-commented source

## 🚀 Getting Started

### Prerequisites

- Any modern web browser (Chrome, Firefox, Safari, Edge)
- No build tools, frameworks, or dependencies required

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Rajadurai001/OIBSIP.git
   ```

2. **Navigate to the project folder**
   ```bash
   cd OIBSIP/WebDevelopment-Level1-PersonalPortfolio
   ```

3. **Open in browser**
   ```bash
   # Simply open index.html in your browser
   # Or use a local server:
   npx serve .
   ```
